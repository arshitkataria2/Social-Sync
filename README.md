# 🌐 SocialySync

🚀 SocialySync is a modern social media platform where users can connect, share posts, interact with others, and stay connected in real time.

---

## ✨ Features

- 🔐 User Authentication
- 📝 Create, Edit & Delete Posts
- ❤️ Like & Comment System
- 👤 User Profiles
- 🤝 Follow / Unfollow Users
- 📷 Media Upload Support
- 📱 Fully Responsive Design
- ⚡ Fast & Interactive UI

---

## 🛠️ Tech Stack

### 🎨 Frontend
- TypeScript.js
- HTML
- CSS
- JavaScript

### ⚙️ Backend
- Node.js
- Express.js

### 🗄️ Database
- MySQL

---

## 📦 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/socialysync.git
```

### 2️⃣ Open Project Folder

```bash
cd socialysync
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Project

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file and add:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=socialysync
JWT_SECRET=your_secret_key
PORT=5000
```
